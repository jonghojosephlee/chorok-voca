# 초록 보카

하루 10개씩 새 단어를 익히고, 퀴즈와 간격 반복으로 복습하는 단어장 웹앱. 홈 화면에 추가하면 앱처럼 전체 화면·오프라인으로 동작합니다.

- 오늘의 학습: 새 단어 카드 → 확인 퀴즈, 틀린 문제는 3문제 뒤 다시 출제
- 복습: 뜻 고르기 · 단어 고르기 · 동의어 · 듣고 고르기 · 스펠링 (또는 알아요/몰라요 카드)
- 카드 넘겨보기, 자동 재생 듣기 모드, 즐겨찾기, 오답노트, 테스트, 학습 기록
- 학습 기록은 기기 안(localStorage)에만 저장되고, 진행 중인 학습은 나갔다 와도 이어서 할 수 있습니다

단어 목록과 발음 파일(`data/`)은 AES-GCM으로 암호화돼 있어, 처음 실행할 때 받은 코드로만 열 수 있습니다.
발음: Kokoro-82M (Apache-2.0).

## 개발

`src/`에 앱 소스(`logic.js`, `app.js`, `style.css`, `shell.html`, `sw.js`)가 있고, `tools/build.py`가 이를 합쳐 `index.html`을 만들고 단어·발음을 암호화합니다. 단어 원본과 발음 원본 파일은 이 저장소에 포함하지 않습니다. `tools/test_logic.js`는 출제·복습 로직 테스트입니다.
