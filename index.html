단어 파일 불러오기

Mac에서 iCloud Drive에 넣어둔 chorok-voca-data.json을 골라주세요. 한 번 불러오면 인터넷 없이도 이 폰에서 계속 쓸 수 있어요.

  1. 아래 ‘파일 선택’을 누르고 ‘찾아보기’로 가요
  2. iCloud Drive에서 chorok-voca-data.json을 눌러요

먼저 홈 화면에 추가해 주세요. 여기서 불러오면 홈 화면 앱에는 옮겨지지 않아요. Chrome 주소창 오른쪽 공유 버튼 → ‘홈 화면에 추가’ 후, 홈 화면의 초록 보카 아이콘으로 열어서 불러오세요.

앱처럼 쓰려면 Chrome 주소창 오른쪽 공유 버튼 → ‘홈 화면에 추가’를 눌러요. 그다음부터는 홈 화면 아이콘으로 여세요.
