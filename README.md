# 초록 보카

하루 5~10개씩 새 단어를 익히고, 퀴즈와 간격 반복으로 복습하는 단어장 웹앱. 홈 화면에 추가하면 앱처럼 전체 화면·오프라인으로 동작합니다.

- 오늘의 학습: 새 단어와 복습(하루 10개, 설정에서 20·30개)을 3단계로 나눠서 하고, 한 단계를 끝낼 때마다 동그라미가 한 칸씩 채워집니다
- 문제: 뜻 고르기 · 단어 고르기 · 동의어 · 듣고 고르기 · 예문 빈칸 · 문장 속 뜻 · 뜻 모두 고르기 · 짝 맞추기 (또는 알아요/몰라요 카드). 보기는 이미 배운 단어에서 나옵니다
- 카드 보기(알면 오른쪽, 모르면 왼쪽), 자동 재생 듣기 모드, 즐겨찾기, 오답노트, 테스트, 학습 기록
- 학습 기록은 기기 안(localStorage)에만 저장되고, 진행 중인 학습은 나갔다 와도 이어서 할 수 있습니다

단어 목록과 발음 파일(`data/`)은 AES-GCM으로 암호화돼 있어, 처음 실행할 때 받은 코드로만 열 수 있습니다.
발음: Kokoro-82M (Apache-2.0).

## 개발

`src/`에 앱 소스(`logic.js`, `app.js`, `style.css`, `shell.html`, `sw.js`)가 있고, `tools/build.py`가 이를 합쳐 `index.html`을 만들고 단어·발음을 암호화합니다. 단어 원본과 발음 원본 파일은 이 저장소에 포함하지 않습니다. `tools/test_logic.js`는 출제·복습 로직 테스트, `tools/sim_pace.js`는 설정별 하루 문제 수·기억 정도 시뮬레이션입니다.
